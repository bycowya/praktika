# Численное интегрирование

Приложение для численного вычисления определённых интегралов методами
прямоугольников (левого, правого, среднего), трапеций и Симпсона.

**Студент:** Иванов И.И.

---

## Возможности

- Ввод функции строкой (например, `x**2 + 3*x - 1`, `sin(x) + cos(x)`)
- Пять методов численного интегрирования:
  - метод левых прямоугольников,
  - метод правых прямоугольников,
  - метод средних прямоугольников,
  - метод трапеций,
  - метод Симпсона.
- Точное значение интеграла через символьные вычисления (`sympy.integrate`)
- Расчёт погрешности для каждого метода
- График разбиения с закраской фигур (прямоугольники, трапеции, параболы)
- Таблица значений и погрешностей для разного числа разбиений `n`
- Экспорт результатов в CSV и JSON
- Обработка расходящихся интегралов (например, `log(x)` на `[0, 1]`)

## Примеры использования

| Функция | a | b | Точное значение |
|---|---|---|---|
| `x**2` | 0 | 1 | 0.3333333333 |
| `sin(x)` | 0 | 3.14159265 | 2.0 |
| `exp(x)` | 0 | 1 | 1.7182818285 |
| `log(x)` | 1 | 2 | 0.3862943611 |
| `x**3 + 2*x` | 0 | 2 | 8.0 |

**Важно:** для `log(x)` нижний предел `a` должен быть больше нуля —
иначе интеграл расходится, и приложение покажет предупреждение.

## Тесты

```bash
pytest tests/ -v
```

Покрытие:

```bash
pytest tests/ --cov=core --cov=io_utils --cov-report=term-missing
```

Ожидаемый результат: **42 теста, 100% покрытие**.

### Что тестируется

- **Парсер** (`test_parser.py`) — валидация формул, регистр, `ln`/`log`,
  защита от `eval`/`import`/`__`.
- **Численные методы** (`test_methods.py`) — корректность формул,
  граничные случаи (`n = 1`), особенности (`log(0)`).
- **Обработка ошибок** (`test_errors.py`) — точное значение,
  погрешность, расходящиеся интегралы.
- **Экспорт** (`test_exporter.py`) — CSV, JSON, пустые данные, `None`.
- **Интеграционные** (`test_integration.py`) — полная цепочка
  `parse → exact → method → error`, тесты из `data/test_cases.json`.

## Инструкция по Docker (для новичков)

### 1. Установите Docker

- **Windows / macOS:** скачайте с https://www.docker.com/products/docker-desktop
  и установите. Запустите Docker Desktop.
- **Linux:** `sudo apt install docker.io`

Проверьте установку:

```bash
docker --version
```

### 2. Соберите образ

Из папки проекта:

```bash
docker build -t integration-app .
```

Флаг `-t integration-app` — имя образа. Точка `.` — текущая папка.

### 3. Запустите контейнер

```bash
docker run -p 8501:8501 integration-app
```

Флаг `-p 8501:8501` — проброс порта из контейнера в систему.

### 4. Откройте приложение

http://localhost:8501

### 5. Остановите контейнер

`Ctrl+C` в терминале, где запущен контейнер. Или в другом терминале:

```bash
docker ps
docker stop <container_id>
```

### Частые проблемы

| Проблема | Решение |
|---|---|
| `docker: command not found` | Docker Desktop не запущен |
| Порт 8501 занят | `docker run -p 8502:8501 integration-app`, откройте `localhost:8502` |
| Долго собирается | первый раз — нормально, кэшируется |
| Изменения в коде не подхватываются | `docker build --no-cache -t integration-app .` |
